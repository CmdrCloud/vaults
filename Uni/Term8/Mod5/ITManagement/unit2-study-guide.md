# Unit 2 — ITIL Study Guide

## What is ITIL?

- **Information Technology Infrastructure Library**: set of best practices for IT
- Purpose: align IT services with business needs, standardise processes,
improve quality/efficiency/security
- Benefits: reduce risks, optimise costs, improve client satisfaction,
enable continuous improvement

## ITIL Versions

| Version | Focus |
|---------|-------|
| v1 & v2 | Technical & Operative Processes |
| v3 | **Lifecycle** (strategy, design, transition, operation, improvement) |
| v4 | **Cloud** & cloud-native services |
| v5 (2026) | **AI** |

## ITIL Lifecycle (v3)

```
1. Service Strategy
2. Service Design
3. Service Transition
4. Service Operation
5. Continual Service Improvement (CSI)
```

### 1. Service Strategy

- **What**: vision & strategy for IT services
- **Key processes**: Service Portfolio Mgmt, Financial Mgmt, Demand Mgmt

### 2. Service Design

- **What**: design new/modified services per business needs
- **Key processes**: Service Level Mgmt, Capacity Mgmt, Availability Mgmt,
Cybersecurity Mgmt, IT Service Continuity, Service Catalogue

### 3. Service Transition

- **What**: build, test, deploy to production with minimal risk
- **Key processes**: Change Mgmt, CMDB (Configuration Mgmt),
Release & Deployment Mgmt, Service Testing & Validation

### 4. Service Operation

- **What**: keep services running day-to-day
- **Key processes**: Incident Mgmt, Problem Mgmt, Service Request, Event Mgmt,
Access Mgmt

### 5. Continual Service Improvement (CSI)

- **What**: evaluate & improve everything continuously
- **Key processes**: SLA review, process maturity evaluation, PDCA,
user surveys & KPIs

## Service Value System (SVS)

- Describes how all components work together to create **value**
- Flow: **Opportunity/Demand** → Guiding Principles →
Governance → Service Value Chain → Practices → Continual Improvement → **Value**

## 4 Dimensions

1. **Organisation & People**
2. **Information & Technology**
3. **Associates & Providers**
4. **Value Flows & Processes**

## Outsourcing

- Hiring an external provider to manage IT services
- Types: Total, Partial, Offshore, Onsite
- Risks: loss of control, security, communication, dependency, variable quality, loss of internal knowledge

## Key Certifications

- ISO/IEC 20000
- ITIL Foundation
- COBIT & ISO 27001

## Planning → Delivery → Operation → CSI

| Phase | Objective | Key Processes |
|-------|-----------|---------------|
| **Planning** | Align services with strategic goals | Portfolio, Demand, Financial, Capacity & Availability Mgmt |
| **Delivery** | Secure, minimal-impact changes | Change Mgmt, CMDB, Release & Deployment |
| **Operation** | Daily functionality + user support | Incident, Problem, Event, Access Mgmt |
| **CSI** | Constant performance review | SLA review, PDCA, KPIs, satisfaction surveys |

## Perspectives

- **Financial**: reduce costs
- **Clients**: improve satisfaction
- **Internal**: optimise incident mgmt
- **Learning**: train IT personnel
