1Objetivo de la Clase

Esta es la clase de cierre del modulo. Se compila la app en dos formatos reales: un APK para instalar en celulares Android y una version Web para abrir en el navegador sin Flutter instalado. Tambien se explica el proceso para iOS.

  • Configurar el AndroidManifest.xml con los permisos necesarios para Android.
  • Cambiar la URL del servidor para que el celular fisico pueda conectarse a XAMPP.
  • Compilar el APK con flutter build apk --release e instalarlo en un celular Android real.
  • Compilar para Web con flutter build web --release y publicar en XAMPP.
  • Entender que se necesita para compilar para iOS y las alternativas gratuitas disponibles.

2Preparar el AndroidManifest.xml

Abrir el archivo android/app/src/main/AndroidManifest.xml en VS Code. Hay que agregar dos cosas: el permiso de internet y el atributo que permite conexiones HTTP sin cifrado.

2.1 Permiso de internet

Agregar esta linea justo antes de la etiqueta <application:

<uses-permission android:name="android.permission.INTERNET" />

2.2 Permitir trafico HTTP (cleartext)

Desde Android 9 el sistema bloquea por defecto las conexiones HTTP sin cifrado. XAMPP usa HTTP, no HTTPS. Sin este atributo la app compila pero al abrirla no puede conectarse al servidor y muestra error de red.

Buscar la etiqueta <application que ya existe en el archivo y agregar el atributo android:usesCleartextTraffic="true":

xml — android/app/src/main/AndroidManifest.xml
<manifest xmlns:android=
    "http://schemas.android.com/apk/res/android">

    <!-- Permiso de internet: obligatorio para llamadas HTTP -->
    <uses-permission android:name=
        "android.permission.INTERNET" />

    <application
        android:label="app_vehiculos"
        android:name="${applicationName}"
        android:icon="@mipmap/ic_launcher"
        android:usesCleartextTraffic="true">
        <!-- El resto del contenido no cambia -->
Por que Android bloquea HTTP por defecto

Desde Android 9 (API 28) el sistema operativo protege al usuario bloqueando conexiones HTTP sin cifrado en redes publicas inseguras. El atributo usesCleartextTraffic="true" desactiva esta proteccion para permitir la conexion al servidor local durante el desarrollo. En un proyecto real de produccion el servidor deberia usar HTTPS y este atributo no seria necesario.

3Cambiar la URL para el celular fisico

Durante el curso se usaba localhost porque Flutter corria en Chrome en la misma computadora que XAMPP. Un celular fisico es un dispositivo diferente en la red. Cuando el celular escribe localhost se refiere a si mismo, no a la computadora donde esta XAMPP. Hay que usar la IP real de la computadora.

3.1 Obtener la IP de la computadora

Abrir el menu Inicio en Windows, buscar CMD y ejecutar:

ipconfig

Buscar la seccion Adaptador de LAN inalambrica WiFi y copiar el valor de Direccion IPv4. Ejemplo: 192.168.1.15. El celular debe estar conectado a la misma red WiFi que la computadora.

3.2 Actualizar api_service.dart

Abrir lib/api_service.dart y comentar la opcion activa actual, luego descomentar y editar la opcion de IP local:

dart — lib/api_service.dart (seccion de configuracion de URL)
// Comentar la opcion que estaba activa (localhost):
// static const String _baseUrl =
//     'http://localhost:8080/vehiculos_api';

// Activar esta opcion con la IP real de la computadora:
static const String _baseUrl =
    'http://192.168.1.X:8080/vehiculos_api';
// Reemplazar 192.168.1.X con la IP real de ipconfig.
// Cambiar 8080 por 80 si XAMPP usa el puerto 80.
El celular y la computadora deben estar en la misma red WiFi

Si el celular usa datos moviles y la computadora usa WiFi, la conexion no funciona aunque la IP este correcta. Ambos deben estar conectados al mismo router WiFi. Verificar esto antes de compilar.

4Compilar el APK para Android

Con el AndroidManifest.xml configurado y la URL actualizada, abrir el menu Terminal en VS Code, clic en New Terminal y ejecutar:

terminal
flutter build apk --release

La primera compilacion tarda entre 2 y 5 minutos. Al terminar muestra un mensaje similar a:

Built build/app/outputs/flutter-apk/app-release.apk (18.2MB).

4.1 Ubicar el archivo APK

Abrir el Explorador de Windows y navegar a la carpeta del proyecto. El APK se encuentra en:

build/app/outputs/flutter-apk/app-release.apk

4.2 Instalar en el celular Android

  1. Compartir el archivo app-release.apk al celular por WhatsApp, cable USB o Google Drive.
  2. En el celular abrir Ajustes y buscar Seguridad o Aplicaciones. Activar la opcion Instalar apps de fuentes desconocidas o Permitir esta fuente.
  3. Abrir el archivo APK desde el administrador de archivos del celular. Android muestra una advertencia de seguridad. Tocar Instalar de todas formas.
  4. La app aparece en el inicio del celular con el nombre App Vehiculos.
  5. Abrir la app y verificar que la lista de vehiculos carga desde el servidor XAMPP.
Verificar que XAMPP esta accesible desde el celular

Antes de abrir la app en el celular, abrir el navegador del celular y escribir la URL del servidor directamente: http://192.168.1.X:8080/vehiculos_api/get_vehiculos.php. Si aparece el JSON con los vehiculos, el celular puede alcanzar el servidor y la app funcionara. Si no aparece nada, verificar que ambos dispositivos estan en la misma red WiFi y que el firewall de Windows no bloquea el puerto de XAMPP.

5Compilar para Web

Cambiar la URL de vuelta a localhost antes de compilar Web

La version Web corre en el mismo navegador de la computadora donde esta XAMPP. Hay que volver a activar la opcion de localhost en api_service.dart antes de ejecutar flutter build web. Si se compila con la IP del celular la version Web apunta a esa IP en lugar de localhost.

dart — lib/api_service.dart (revertir a localhost para compilar Web)
// Volver a activar localhost para la version Web:
static const String _baseUrl =
    'http://localhost:8080/vehiculos_api';

Luego compilar:

terminal
flutter build web --release

El resultado se genera en la carpeta build/web/ del proyecto.

5.1 Publicar en XAMPP

  1. Abrir el Explorador de Windows y navegar a la carpeta build/web/ del proyecto.
  2. Copiar toda la carpeta web dentro de C:/xampp/htdocs/.
  3. Renombrar la carpeta copiada a app_vehiculos_web.
  4. Abrir Chrome y escribir: http://localhost:8080/app_vehiculos_web
  5. La app se abre en el navegador sin necesitar flutter run. Es la version de produccion.
Diferencia entre flutter run y flutter build web

flutter run -d chrome ejecuta la app en modo debug con el servidor de desarrollo de Flutter activo. flutter build web genera archivos estaticos optimizados que funcionan en cualquier servidor web sin necesitar Flutter instalado. Son dos cosas distintas: una es para desarrollar, la otra es para distribuir.

6iOS: que se necesita (solo explicativo)

No hay practica en esta seccion. Es informacion para que el estudiante sepa que se necesita si en el futuro quiere publicar la app en iPhone.

Requisitos obligatorios sin excepcion

RequisitoDetalle
Una Mac MacBook Air, MacBook Pro, Mac Mini o iMac. No hay forma oficial de compilar para iOS desde Windows o Linux. Es una decision de Apple, no una limitacion de Flutter.
macOS actualizado Apple exige que Xcode solo funcione en las ultimas versiones de macOS. Si el macOS esta desactualizado, Xcode no se instala.
Xcode La herramienta de desarrollo de Apple. Se descarga gratis desde la Mac App Store pero ocupa aproximadamente 15 GB de almacenamiento.
Cuenta Apple Developer Gratuita para probar la app en tu propio iPhone por cable. 99 USD al anno para publicar en la App Store y distribuir a otros usuarios.

El comando (requiere Mac con Xcode)

flutter build ios --release

Alternativas gratuitas sin Mac

ServicioCostoComo funciona
Codemagic Gratuito 500 min/mes Especializado en Flutter. Se conecta al repositorio de GitHub y compila automaticamente en una Mac real en sus servidores. Es la opcion mas simple para estudiantes. La primera compilacion tarda entre 15 y 20 minutos.
GitHub Actions Gratuito para repos publicos Se configura un archivo YAML que define los pasos de compilacion. GitHub ejecuta ese proceso en una maquina Mac virtual. Requiere mas configuracion inicial que Codemagic.
Bitrise Plan gratuito limitado Plataforma de CI/CD movil con soporte para Flutter. El plan gratuito permite compilaciones con tiempos de espera mayores.
Lo que SI pueden hacer los usuarios de iPhone sin Mac

Abrir la version Web compilada en el paso anterior desde Safari o Chrome del iPhone escribiendo la URL del servidor. No es una app nativa instalada desde la App Store pero es completamente funcional para demostrar el proyecto.

7Problemas Frecuentes

ProblemaSolucion
El APK compila pero al abrirlo en el celular no carga los vehiculos y muestra error de red. Verificar en orden: que XAMPP tiene Apache y MySQL en verde, que la IP en api_service.dart es la correcta (verificar con ipconfig), y que el celular y la computadora estan en la misma red WiFi. Probar abriendo la URL del servidor en el navegador del celular.
Android bloquea la instalacion del APK con un mensaje de seguridad. Es el comportamiento normal de Android al instalar apps fuera de la Play Store. Ir a Ajustes del celular y activar la opcion de instalar apps de fuentes desconocidas. La ubicacion exacta varia segun la marca del celular: puede estar en Seguridad, en Aplicaciones o en Privacidad.
La version Web en XAMPP abre pero muestra error al cargar los datos. Verificar que la URL en api_service.dart estaba en localhost al momento de ejecutar flutter build web. Si se compilo con la IP del celular, la version Web no puede conectarse. Corregir la URL y volver a compilar.
Error durante la compilacion: Gradle task assembleRelease failed. Problema de configuracion de Android. Verificar que el archivo AndroidManifest.xml no tiene errores de sintaxis en los cambios que se hicieron. Abrir el archivo y verificar que todas las etiquetas XML estan correctamente cerradas.
El firewall de Windows bloquea la conexion desde el celular al servidor XAMPP. Abrir el Panel de Control de Windows, ir a Sistema y Seguridad, Firewall de Windows Defender y agregar una regla de entrada para el puerto 80 o 8080 segun el puerto de XAMPP. Alternativamente desactivar temporalmente el firewall para la red privada.
