## Introduction

Machine learning is about creating programs that can learn from data.

Instead of being told to do a task, these programs improve as they are exposed
to more data.

This learning process allows them to make predictions or decisions without being
directly told how to do so.

### ML Engineer

An ML Engineer focuses on these three things when working on an ML system:

- building
- deploying
- maintaining

They bridge the gap between data science and software engineering,
taking models developed by data scientists and making them:

- scalable
- reliable
- efficient
- for real-world applications

The above involves tasks like:

- data pipeline construction
- model deployment
- performance monitoring
- infrastructure management
